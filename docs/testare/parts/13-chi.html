13. Chitanțe / încasări

Chitanțele se pot emite pe două căi complet diferite, care trebuie testate separat:

CaleCând se foloseșteSecțiune
A. Fereastra „Generezi și chitanță?”Imediat după printarea unei facturi — clientul plătește pe loc13.1
B. Chitanțe → „Chitanță nouă”Încasarea unor facturi mai vechi, din soldul clientului; se pot încasa mai multe facturi pe o singură chitanță13.2

13.1 Chitanța emisă direct după factură

TC-CHI-001Fereastra de chitanță după printarea facturiiCritică
Rol: AgentEcran: WizardDurată: ~5 min
Pași
  1. Emite o factură completă.
  2. La apariția ferestrei, verifică toate elementele afișate, fără a apăsa nimic.
Rezultat așteptat
  • Titlu: „Generezi și chitanță?”, descriere: „Alege tipul încasării pentru factura printată.”
  • Se afișează „Total factură: {sumă} RON” — verifică dacă suma este cea cu TVA.
  • Două opțiuni: „Achitată total” (selectată implicit) și „Achitată parțial”.
  • Butoane: „Nu, mulțumesc” și „Salvează chitanța”.

TC-CHI-004Valori invalide la suma achitată parțialMare
Rol: AgentEcran: WizardDurată: ~10 min
Pași
  1. Selectează „Achitată parțial” și golește complet câmpul. Apasă „Salvează chitanța”.
  2. Introdu 0 și salvează.
  3. Introdu -50 și salvează.
  4. Introdu litere: abc și salvează.
  5. Introdu o sumă mai mare decât totalul facturii și salvează.
  6. Introdu suma folosind virgulă zecimală: 123,45.
Rezultat așteptat

  • Virgula zecimală este acceptată și interpretată corect (123,45 = 123.45).
  • Nu se consumă niciun număr de chitanță pentru încercările eșuate — verifică „Număr Curent” din Setări înainte și după.

TC-CHI-007Factură încasată parțial — restul disponibilCritică
Rol: AgentEcran: FacturiDurată: ~10 min
Precondiții
  • O factură cu total cu TVA de 119,00, din care s-au încasat 50,00.
Pași
  1. Reprintează factura din listă.
  2. Citește notificarea privind restul disponibil și notează suma afișată.
  3. Selectează „Achitată parțial” și notează valoarea precompletată.
  4. Compară ambele valori cu calculul manual: 119,00 − 50,00 = 69,00.
  5. Încearcă să încasezi 70,00 (peste rest).
Rezultat așteptat
  • Apare notificarea de forma „Factura are deja încasări. Rest disponibil (estimat cu TVA): … RON.”
  • Verificare esențială: suma afișată trebuie să fie 69,00. Dacă apare o altă valoare (ex. calculată pe baza sumei fără TVA), este un defect de reconciliere și se raportează cu prioritate Critică, notând ambele cifre.
  • Încercarea de a încasa peste rest este respinsă cu mesajul „Suma încasată (…) depășește restul disponibil (…)”.

13.2 Chitanță nouă din soldul clientului

TC-CHI-011Pasul 1 — selectarea parteneruluiMare
Rol: AgentEcran: Chitanță nouăDurată: ~5 min
Pași
  1. Chitanțe → „Chitanță nouă”.
  2. Verifică dacă în căsuța de căutare cursorul este deja poziționat.
  3. Caută după denumire, apoi după CUI (scris cu majuscule: RO12345), apoi după CUI scris cu litere mici: ro12345.
  4. Selectează un partener și apasă „Continuă”.
Rezultat așteptat
  • Titlu „Chitanță nouă”, trei pași: Partener → Factură → Detalii.
  • Sugestia din câmp: „Caută partener...”; cursorul este deja în câmp.
  • Căutarea după denumire funcționează indiferent de majuscule.
  • De verificat: căutarea după CUI cu litere mici. Dacă nu găsește partenerul, se raportează ca defect (căutare sensibilă la majuscule).
  • Butonul „Continuă” este inactiv până la selectarea unui partener.

  • Facturile restante (depășite ca scadență) apar primele.
  • Dacă nu există solduri: „Nu există facturi cu sold”.
